# Vercel Labs agent-skills license evidence

The vendored `vercel-*` Skill snapshots in this repository were sourced from `vercel-labs/agent-skills`.

At the reviewed snapshot, the source repository identified the project as MIT-licensed in repository/README metadata, while a top-level LICENSE file was not included with these Skill directories. This is therefore recorded as **license declaration evidence**, not as a byte-preserved upstream license file.

Downstream redistributors that require a standalone upstream license file should independently verify the current upstream licensing state before redistribution. The Skill files themselves are kept unchanged.
